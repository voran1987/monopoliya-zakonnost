# Монополия: законность и правопорядок

Учебная командная игра в формате «Монополии» по теме 1.4 «Законность и правопорядок. Правовая культура и правосознание» (дисциплина «Правоведение»).

## Как играть
- Играют 2–4 команды. Каждая начинает с 15 баллами.
- Вопросы с вариантами ответов открываются в центре поля, чтобы их видела вся группа; после ответа нажмите «Продолжить». При неверном ответе верный вариант и справка не показываются, чтобы подсказка не досталась другим командам.
- Команда бросает кубики и ходит по полю из 40 клеток.
- На свободной клетке-теме нужно верно ответить на вопрос: тогда тема осваивается за баллы. Если другая команда попадёт на освоенную тему, она платит за консультацию.
- Клетки «Вопрос» дают +2 балла за верный ответ, «Кейс» — случайная ситуация, «Просвещение» — +1 балл, «Правонарушение» отправляет в «Суд». Проход через «Старт» даёт +2 балла.
- Если команда попала на тему, которую освоила другая команда, она отвечает на вопрос: верный ответ освобождает от платы, неверный обязывает заплатить за консультацию.
- Команды могут меняться темами и баллами: кнопка «Обмен» доступна в свой ход, обмен подтверждается после договорённости команд (тема на тему, тема на баллы или только баллы).
- Плата за консультацию зависит от набора: если команда освоила все темы цветного блока (или обе темы блока «Сознание»), плата ×2. В блоке «Надзор и контроль» плата равна базовой, умноженной на число освоенных тем блока (от ×1 до ×4).
- Если баллов не хватает на плату (консультация, штраф, кейс), команда продаёт банку освоенные темы за половину их цены, пока не наберёт нужную сумму. Если не хватает даже после продажи всех тем, команда отдаёт всё, что есть.
- Игра заканчивается кнопкой «Подвести итоги» в любой момент, время партии ведёт преподаватель.
- Побеждает команда с наибольшей суммой баллов и стоимости освоенных тем.

## Запуск
Один файл без сборки: откройте `index.html` в браузере. Для публикации включите GitHub Pages (Settings → Pages → ветка `main`, папка `/root`).
